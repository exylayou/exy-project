HERO PLACEHOLDER IMAGE
======================

This directory should contain the hero_placeholder.jpg file.

For the ExploreScreen hero section, use an image that shows:
- Saint Vincent and the Grenadines landscape
- Tropical beach or scenic island view
- High resolution: Recommended 1200x400px minimum
- File name: hero_placeholder.jpg

If the actual image is not yet available, the ExploreScreen will display
a placeholder background color until the image is added to this directory.

Usage in React Native:
----------------------
Local: source={require('../images/hero_placeholder.jpg')}
Remote: source={{ uri: 'https://your-cdn.com/hero.jpg' }}
