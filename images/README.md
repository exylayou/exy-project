# Images Directory

## Required Images

### Hero Image
- **Filename**: `hero_placeholder.jpg`
- **Purpose**: Hero header background for ToursScreen
- **Recommended dimensions**: 1920x600px or similar wide aspect ratio
- **Description**: Should showcase Saint Vincent and the Grenadines scenic views

## Usage

Place the `hero_placeholder.jpg` file in this directory for the ToursScreen to display it as the hero header background.

If the image is not present, the screen will still function but will show a gray placeholder background.
